## Programme
- BICTN — Bachelor of ICT (Networking Major) — البكالوريوس في تقنية المعلومات والإتصالات (تخصص تصميم الشبكات)
- 4 years, 480 credits, NQF Level 8, **BCS accredited** (The Chartered Institute of IT)
- Major selection: GPA from **IT6003 Networking 1** + **IT6004 Unix Systems**
- Domains: Programming, Data Analytics, Networking, Cloud/CIS, Cyber Security
- PBL philosophy; industry certifications (CCNA/CCNP) encouraged
- Graduate roles: Network admin, 4G/5G integration engineer, Network engineer, ISSO, Network Security Engineer, CCNA/CCNP Engineer

## Study Plan (semester by semester)
### Y1S1: IT6001 Computer Systems · EL6006 English Comm A · IT6010 Maths for Computing · IT6004 Unix Systems
- IT6001: hardware components in computer architectures + install/administer end-user OS; emphasis Cloud Computing
- IT6010: statistical techniques for ICT + advanced geometrical methods for simulation
- IT6004 (UXS, L6, 15cr, Amazon Linux 2 on AWS): Win vs Unix differences · command-line · manage Linux server (files/processes/users) · scripting automation. Labs via Putty/SSH; yum; passwd
### Y1S2: IT6008 Computer Programming 1 · IT6005 Database Systems 1 (Oracle) · EL6007 English Comm B · IT6003 Networks & Data Communications
- IT6008: primitive types, data structures, source→executable translation, problem-solving, testing/debugging
- IT6005: core DB concepts, ERD data modelling, normalization, Oracle SQL
- IT6003: TCP/IP & OSI fundamentals, VLSM IP addressing design, configure networks/routers
### Y2S1: IT6011 Intro to Info Security · IT7001 Systems Analysis & Design · IT6012 Web Fundamentals · ELE1
- IT6011: security value, requirements analysis, practical skills
- IT7001: analyse/model systems, business requirements, logical+physical design, industry standards
- IT6012: multi-page website design, consistent maintainable styling
### Y2S2: IT6000 IT Applied Project · NR National Requirements · IT7003 Networking & Data Comms 2 · IT7004 Operating Systems & Platforms
- IT7003: LANs, VLANs, WANs, switch management, WiFi + AP config, WAN protocols, IP addressing services, device security
- IT7004: enterprise server infrastructure planning/design/installation/configuration/administration
### Y3S1: IT7009 Artificial Intelligence · IT8505 Defence in Depth · IT7301 Ethical Hacking · ELE1
- IT7009: AI building blocks — planning, reasoning, problem-solving, ML, knowledge representation, search, logic
- IT8505: layered DiD security mechanisms protecting CIA
- IT7301: hacker's POV, countermeasures, work-ready security
### Y3S2: IT8323 Advanced Networking · IT8213 Data Centre Management · IT8313 Wireless Communications · ELE1
- IT8323: advanced network tech + heavy troubleshooting, complex scenarios
- IT8213: advanced scripting for admin automation + DC management tools
- IT8313: mobile/wireless infra like Bahrain carriers
### Y4: IT7204 Cloud Security · IT7012 Entrepreneurship & Research Methods · IT7520 Network & Security Programmability · IT8341 Software Defined Networking
- IT7204: securing cloud environments, threat protection
- IT7012: identify/evaluate opportunities, design+conduct applied research, evidence-based decisions
- IT7520: Python — sockets, data encoding, serialization, network automation, APIs, secure app development
- IT8341: SDN
### Y4 optional: IT8399 Co-op Learning Project (Networking) · IT8097 Lean Start-up · IT8098 IT Research Project
